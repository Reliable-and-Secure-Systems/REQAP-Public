# Systolic Hardware Simulator & Safe-FFD Packing

This module acts as the second stage of the pipeline. It is a software-level hardware simulator that implements the **Safe-FFD (First Fit Decreasing)** bin-packing algorithm to bridge the gap between theoretical PyTorch models and physical hardware constraints.

## How it Works
1. **Model Loading:** It loads the pre-trained `.pth` weights and the JSON configs generated by the `quantization_framework`.
2. **Safe-FFD Bin Packing:** The simulator treats each 16-bit hardware register as a "Bin" (`R=16`). It dynamically packs heterogeneous low-bit weights (e.g., 2-bit, 4-bit, 8-bit) as tightly as possible into these 16-bit bins based on their configuration.
3. **Metric Extraction:** It calculates the total number of theoretical memory loads for an 8-bit baseline versus the MQF Packed version, outputting the exact percentage reduction in memory bandwidth.

## How to Run

Before running, ensure you are in the `systolic_sim/` directory.

### Running the Simulator
To execute the hardware simulation and view the extracted theoretical memory metrics, run the main simulator script and provide the model name:

```bash
python simulator.py
```

*Note: Inside `simulator.py`, you can modify the script to call `run_both_modes('VGG11')` or `run_both_modes('ResNet18')` to simulate the different models.*
